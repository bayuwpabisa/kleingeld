## Dependency baru (semua devDependencies)
| Paket | Kenapa |
|---|---|
| `prettier` | Formatter, permintaan jadwal |
| `eslint-config-prettier` | Mematikan aturan ESLint yang bentrok dengan Prettier (direkomendasikan docs Next: `node_modules/next/dist/docs/01-app/03-api-reference/05-config/03-eslint.md`, bagian *With Prettier*) |

## Keputusan
- **Gaya Prettier:** default Prettier 3 (kutip ganda, titik koma, `trailingComma: "all"`, lebar 80). Sudah sama dengan gaya kode create-next-app, jadi perubahan format awal kecil.
- **Prettier tidak memformat Markdown dan `docs/`.** Dokumen ditulis tangan dengan tabel panjang; Prettier akan meratakan ulang tabel dan membuat diff besar tanpa manfaat. Juga diabaikan: `.claude/`, `AGENTS.md` (ditulis ulang oleh `next dev`), `package-lock.json`, `skills-lock.json`, `public/`. File di `.gitignore` sudah otomatis diabaikan Prettier 3.
- **lint-staged:** `*.{js,mjs,cjs,jsx,ts,tsx}` → `eslint --fix --max-warnings=0` lalu `prettier --write`; `*.{json,css}` → `prettier --write`. Commit gagal kalau ada error/warning ESLint yang tidak bisa diperbaiki otomatis.
- **commitlint:** `extends: ["@commitlint/config-conventional"]`, plus `scope-enum` level **warning** (bukan error) berisi scope dari CONTRIBUTING (`transactions, budgets, bills, dashboard, auth, ui, db`) + `deps`. Scope di luar daftar hanya memberi peringatan.
- **Hooks:** `.husky/pre-commit` = `npx lint-staged`, `.husky/commit-msg` = `npx --no -- commitlint --edit "$1"`. Script `"prepare": "husky"` supaya hook terpasang otomatis setelah `npm install` (termasuk di laptop lain).
- **TS lebih ketat (disetujui):** tambah `noUncheckedIndexedAccess: true` di `tsconfig.json`. Akses `arr[i]`/`record[key]` jadi bertipe `T | undefined`, mencegah `undefined`/`NaN` saat menghitung uang. Kode sekarang tidak terdampak (sudah dicek `app/`). Supaya kode tidak memanjang, pakai pola yang tidak terkena opsi ini: `for...of`/`map`/`filter`/`reduce` alih-alih indeks, `Map` + `get() ?? 0` untuk lookup per key, `find`/`.at()` untuk satu elemen, Zod `parse` untuk data dari luar, dan `?? 0` hanya di akses indeks yang memang perlu.
- **Struktur folder:** buat folder dari AGENTS.md dengan `.gitkeep`: `components/`, `lib/`, `db/`, `schemas/`, dan `features/{transactions,budgets,bills,dashboard}/`. Tambah `features/README.md` pendek yang menjelaskan isi standar satu fitur (`components/`, `hooks/`, `api/` untuk query/mutation TanStack, `index.ts` sebagai pintu ekspor) dan aturan impor (fitur boleh impor `components/`, `lib/`, `schemas/`; antarfitur lewat `index.ts`), plus bagian singkat **"Akses data aman"** berisi pola-pola `noUncheckedIndexedAccess` di atas dengan contoh kode pendek.

## Langkah
### 1. Branch
`git switch develop && git pull` → `git switch -c feature/dev-tooling`.

### 2. Prettier — commit `build: add prettier with tailwind class sorting`
- `npm i -D prettier eslint-config-prettier prettier-plugin-tailwindcss`
- `.prettierrc.json`: `{ "plugins": ["prettier-plugin-tailwindcss"], "tailwindStylesheet": "./app/globals.css" }`
- `.prettierignore` sesuai keputusan di atas.
- `eslint.config.mjs`: `import prettier from "eslint-config-prettier/flat"` dan taruh `prettier` setelah `...nextTs` (harus terakhir di antara config aturan).
- `package.json` scripts: `"typecheck": "tsc --noEmit"`, `"format": "prettier --write ."`, `"format:check": "prettier --check ."`.
- Tambah `.vscode/`? **Tidak**, folder editor tidak ikut repo.

### 3. Format awal — commit `style: format codebase with prettier`
`npm run format`, lalu cek diff (perkiraan: urutan class Tailwind di `app/page.tsx`/`app/layout.tsx`, sedikit di config). Dipisah supaya commit langkah 2 bersih.

### 4. Hooks — commit `build: add husky, lint-staged and commitlint`

- `npx husky init` (membuat `.husky/pre-commit` + script `prepare`), lalu isi `.husky/pre-commit` dan buat `.husky/commit-msg` seperti di Keputusan.
- `lint-staged` config di `package.json` (key `"lint-staged"`), `commitlint.config.mjs` di root.

### 5. TS + folder — commit `chore: add feature folder structure and stricter tsconfig`
`tsconfig.json` + folder/`.gitkeep` + `features/README.md`.
