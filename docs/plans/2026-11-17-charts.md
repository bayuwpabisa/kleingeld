# Plan 17 Nov 2026: Grafik tren bulanan + per kategori (Recharts) + alternatif aksesibel

Dikerjakan mulai 23 Nov (jadwal bergeser; task dikerjakan berurutan).

## Context
Task jadwal 17 Nov: **Grafik tren bulanan + per kategori (Recharts) + alternatif aksesibel → "2 grafik terbaca screen reader"**. Setelah 16 Nov (PR #23, develop `234c8bf`), `/dashboard` berisi kartu ringkasan bulan ini dan Transaksi terbaru, dengan data diprefetch di server lalu di-hydrate ke cache TanStack. Wireframe 03 menaruh dua kartu grafik di antara kartu ringkasan dan grid bawah. DESIGN.md › Grafik sudah menetapkan: tren = bar berkelompok pemasukan vs pengeluaran 6 bulan, legend 2 seri, label nilai hanya di bulan berjalan; per kategori = bar horizontal berperingkat (bukan donut), satu warna `chart-expense`, maks. 5 kategori + "Lainnya"; grid/sumbu `border`/`fg-muted`; satu sumbu Y; tooltip hover/fokus; tombol "Lihat sebagai tabel". Token `--chart-income`/`--chart-expense` sudah ada di `app/globals.css` dan sudah lolos validator dataviz (terang + gelap).

Keputusan user (23 Nov):
- **Seed demo diperpanjang jadi 6 bulan**, supaya grafik tren demo penuh. Grafik selalu 6 bulan untuk semua user; bulan tanpa transaksi tampil Rp0.
- **Urutan: Tren lalu Per kategori di semua lebar** (wireframe desktop; menyimpang dari wireframe HP yang menaruh Per kategori di atas, karena urutan Tab harus = urutan visual). Dicatat di DESIGN.md.
- **"Lihat sebagai tabel" menukar grafik ↔ tabel di tempat yang sama** (label jadi "Lihat sebagai grafik", `aria-pressed`), tinggi kartu tetap.

Keputusan saya (plan disetujui user 23 Nov tanpa koreksi):
- Per kategori = **pengeluaran bulan ini** (sama dengan konteks "bulan ini" di kartu ringkasan; key filter = `currentMonthFilters(today)`).
- Tren = bulan berjalan + 5 bulan sebelumnya, dihitung dari `today` (prop dari server, seperti `MonthSummary`).
- Tabel per kategori berisi baris yang sama dengan grafik (5 + Lainnya), ditambah kolom persen dari total; tabel tren berisi 6 bulan × pemasukan, pengeluaran, saldo.
- Bar kategori diberi nama kategori di kiri dan nominal di ujung bar (6 bar, nilai adalah isi utama); tren tanpa label kecuali bulan berjalan (DESIGN.md).
- Sumbu Y tren memakai angka ringkas `Intl.NumberFormat("id-ID", { notation: "compact" })` ("1,2 jt"); tooltip dan tabel memakai `Money`/format penuh.
- State toggle tabel/grafik (`useState`) boleh tetap saat halaman tersembunyi (preferensi tampilan, seperti panel filter), jadi tanpa `useResetOnHide`; dicek di browser.
- Tidak sekarang: klik bar → filter Transaksi, pemilih periode/bulan, banding bulan lalu, dynamic import Recharts (itu task 20 Nov; komponen grafik dibuat di file sendiri supaya mudah di-`next/dynamic`).

## Rancangan

### Data (server → cache client, pola 16 Nov)
- **Repo** `features/transactions/server/transactions-repo.ts` (ambil `db` + userId, semua query di-scope ke user):
  - `monthlyTotals(db, userId, { from, to })` → `{ month: "YYYY-MM", income, expense }[]` untuk setiap bulan di rentang, bulan kosong diisi 0 (helper murni `fillMonths`). Pengelompokan per bulan memakai `sql` Drizzle (`to_char(date, 'YYYY-MM')`), alasannya Drizzle tidak punya helper bucket tanggal; ditulis di komentar.
  - `totalsByCategory(db, userId, { from, to, type })` → `{ categoryId, name, icon, total, count }[]` urut total turun.
  - `sum` bigint → `.mapWith(Number)` seperti `summarizeTransactions`.
- **Schema** `schemas/transaction.ts`: query + DTO untuk keduanya (Zod, dipakai route dan client; `z.infer`).
- **Route** `app/api/transactions/trend/route.ts` dan `app/api/transactions/by-category/route.ts` (GET, `getCurrentUser` → 401, Zod → 400 dengan bentuk error yang ada di `lib/api/http.ts`). Pola dari `app/api/transactions/summary/route.ts`.
- **Client**: `transactionKeys.trend(range)` dan `transactionKeys.byCategory(filters)` di `features/transactions/api/keys.ts`, **di bawah `transactionKeys.all`**, jadi mutation yang ada (`invalidateQueries({ queryKey: transactionKeys.all })` di `use-create/update/delete-transaction.ts`) otomatis me-refetch grafik. Fetch di `fetch-transactions.ts`, hook `use-monthly-trend.ts`, `use-category-totals.ts` (pola `use-transaction-summary.ts`).
- **Dashboard**: `dashboard-queries.ts` + `trendRange(today)` (6 bulan, pakai `monthRange` dari `features/transactions/periods.ts`); `server/prefetch-dashboard.ts` + `prefetchMonthlyTrend`, `prefetchCategoryTotals` (QueryClient per request yang sama, gagal → tidak di-dehydrate → client ambil sendiri + error state).
- Helper murni `rankCategories(rows)` → 5 teratas + "Lainnya" (jumlah sisanya) mulai 7 kategori; tepat 6 kategori ditampilkan semua (diputuskan di G3, lihat catatannya).

- `monthly-trend.tsx` + `monthly-trend-section.tsx` (Server Component, `requireUser` → `todayInJakarta` → prefetch → `HydrationBoundary`), `category-breakdown.tsx` + `category-breakdown-section.tsx`. Masing-masing di `<Suspense>` sendiri di `app/(app)/dashboard/page.tsx` dengan skeleton komponen yang sama tanpa data.
- Pembaca layar ("terbaca screen reader"): grafik dibungkus `<figure>` dengan `<figcaption>` berisi kalimat ringkasan (misal "Pengeluaran November 2026: terbesar Makan Rp1.275.000, lalu …"; "Juni–November: pemasukan tertinggi …"), SVG grafik tidak menggandakan isi itu; tabel memakai `<table>` dengan `<caption>`, `<th scope>`. Keyboard tooltip memakai `accessibilityLayer` Recharts (dicek di browser: Tab ke grafik, panah kiri/kanan).
- Warna: `fill="var(--chart-income)"` / `var(--chart-expense)`, grid `var(--border)`, teks sumbu `var(--fg-muted)`, jadi dark mode ikut token tanpa kode tambahan. Bar sudut 4px di ujung data, celah 2px antar bar (dataviz › marks).
- States per kartu: skeleton (tinggi sama), error + "Coba lagi" (`ErrorState bare`), offline (`fetchStatus === "paused"`), kosong: tren semua 0 → "Belum ada transaksi dalam 6 bulan terakhir."; kategori tanpa pengeluaran bulan ini → "Belum ada pengeluaran bulan ini." (`EmptyState bare`).
- Tata letak: HP 1 kolom (ringkasan → Tren → Per kategori → grid bawah). Desktop: Tren lebar + Per kategori sempit (wireframe ±2/3 + 1/3); breakpoint diukur di browser (di 1024px kartu 1/3 mungkin terlalu sempit untuk nama kategori + nominal, kalau begitu bertumpuk sampai 1280/1440). Pakai breakpoint arbitrer untuk kedua kelas (gotcha Tailwind v4 di AGENTS.md).
