## Skema (`db/schema.ts`)
- `transactionType` = `pgEnum("transaction_type", ["income", "expense"])`, dipakai kategori dan transaksi.
- `users` (inti Better Auth): `id text PK`, `name text not null`, `email text not null unique`, `emailVerified boolean not null default false`, `image text`, `createdAt`/`updatedAt timestamptz not null default now()` (`updatedAt` dengan `$onUpdate`).
- `categories`: `id uuid PK defaultRandom`, `userId text → users.id ON DELETE CASCADE`, `name text`, `type transactionType`, `icon text` (nama ikon lucide), `isDefault boolean default false`, timestamps. Unique `(userId, type, name)`.
- `transactions`: `id uuid PK`, `userId → users.id CASCADE`, `categoryId uuid → categories.id RESTRICT`, `type`, `amount bigint(number)` + check `> 0`, `date date(string)`, `note text` nullable, timestamps. Index `(userId, date)` dan `(userId, categoryId, date)` untuk daftar, filter, dan grafik.
- `relations()` users↔categories↔transactions untuk `db.query`. Tipe diturunkan dengan `$inferSelect`/`$inferInsert`.
- Budget dan tagihan (termasuk `billId` + `billPeriod` di transaksi) **tidak** dibuat hari ini, tapi masing-masing di 18 dan 19 Nov.

## File
- `drizzle.config.ts`: `import "./db/load-env"`, `schema: "./db/schema.ts"`, `out: "./db/migrations"`, `dialect: "postgresql"`, `casing: "snake_case"`, `strict: true`, url = `DATABASE_URL_UNPOOLED ?? DATABASE_URL` (lempar error jelas kalau kosong).
- `db/load-env.ts`: `loadEnvConfig(process.cwd())`. Diimpor paling atas oleh config dan skrip, karena urutan evaluasi impor ESM membuat `loadEnvConfig` harus jalan sebelum `db/index.ts`.
- `db/index.ts`: lempar error kalau `DATABASE_URL` kosong; `new Pool({ connectionString })`, `attachDatabasePool(pool)`, ekspor `db = drizzle({ client: pool, schema, casing: "snake_case" })`, `pool`, dan tipe `Db`. Tidak memakai `server-only` karena modul ini juga dijalankan oleh skrip Node.
- `db/migrations/`: hasil `drizzle-kit generate` (`0000_*.sql` + `meta/`), di-commit. Ditambahkan ke `.prettierignore`.
- `db/default-categories.ts`: daftar kategori bawaan `{ name, type, icon }`. Pengeluaran: Makan (utensils), Transport (bus), Tagihan (receipt), Hiburan (clapperboard), Belanja (shopping-bag), Kesehatan (heart-pulse). Pemasukan: Gaji (wallet), Freelance (laptop), Lainnya (coins). Besok dipakai juga untuk user baru.
- `db/demo/demo-user.ts`: konstanta `DEMO_USER` (`id: "demo"`, `email: "demo@kleingeld.app"`, `name: "Akun Demo"`, sama dengan wireframe), plus kategori custom demo "Kopi & jajan" (coffee).
- `db/demo/build-demo-transactions.ts`: **fungsi murni** `buildDemoTransactions({ today, categories })` yang mengembalikan baris transaksi (tanpa DB). PRNG kecil (mulberry32) ditulis inline. Pola per bulan: Gaji Rp8.500.000 tanggal 25, Freelance sesekali, Tagihan (listrik, internet, pulsa) di awal bulan, Makan hampir tiap hari, Transport di hari kerja, Kopi & jajan, Hiburan/Belanja/Kesehatan sesekali. Nominal dibulatkan ke Rp500, catatan berbahasa Indonesia, tanggal tidak melewati `today`. Setiap bulan penuh berakhir dengan saldo positif.
- `db/demo/build-demo-transactions.test.ts` (`@jest-environment node`), ditulis lebih dulu (TDD):
  - semua tanggal ada di rentang [tgl 1 dua bulan lalu, today];
  - ada Gaji di setiap bulan penuh;
  - nominal berupa integer > 0;
  - tipe transaksi sama dengan tipe kategorinya;
  - input sama menghasilkan output sama (deterministik);
  - pengeluaran < pemasukan di bulan penuh;
  - di awal bulan (today = tgl 1) tetap aman.
- `db/demo/seed-demo-user.ts`: `seedDemoUser(db, today = new Date())` dalam satu `db.transaction`. Upsert `DEMO_USER`, hapus transaksi lalu kategori milik demo, insert kategori bawaan + custom (`returning`), lalu insert hasil `buildDemoTransactions`. Mengembalikan jumlah baris. Fungsi ini nanti dipanggil oleh login demo (10 Nov) dan cron.
- `db/seed.ts`: CLI, `import "./load-env"` di urutan pertama, panggil `seedDemoUser(db)`, cetak jumlah kategori dan transaksi, lalu `pool.end()`.
- `package.json` scripts: `db:generate` (`drizzle-kit generate`), `db:migrate` (`drizzle-kit migrate`), `db:studio` (`drizzle-kit studio`), `db:seed` (`tsx db/seed.ts`).
